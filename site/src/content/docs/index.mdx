## What it does

<CardGrid>
	<Card title="Agents across sessions and machines" icon="laptop">
		Panes keep running when you detach. Every agent is marked working,
		blocked or idle. Agents message each other with `klark msg`, in the same
		session, another session, or on another machine.
	</Card>
	<Card title="A chat view for every agent" icon="comment">
		The hub turns each pane into a Claude-style chat: Claude Code, Devin,
		Codex, any other agent, and plain shells as command blocks. The live
		terminal is one click away.
	</Card>
	<Card title="Self-hosted hub with LDAP" icon="setting">
		One container, one port, SQLite on a volume. Sign in with your LDAP or
		Active Directory. Machines dial out over plain HTTP, so no inbound port
		and no tunnel.
	</Card>
</CardGrid>

## 60-second quickstart

You need klark and Docker (or the .NET 10 SDK to run the hub from source).

<Steps>

1. Get klark: [download a binary from the latest GitHub release](/start/install/), or build it (Rust and Zig 0.16).

   ```sh
   cargo build --release
   ./target/release/klark -s
   ```

   `klark` starts the background server and attaches; `-s` names the session after the current folder.
   Detach with `ctrl+b q` and the panes keep running. `klark status` shows what is running.

2. Start a hub, with Docker.

   ```sh
   docker run -d --name klarkhub -p 7470:7470 -v klarkhub-data:/data \
     ghcr.io/muthuishere/klarkhub:latest
   ```

   Open `http://localhost:7470` and sign in as `admin` / `adminadmin`. Change the password when the banner asks.
   From source instead: `cd hub && dotnet run` (listens on `http://localhost:7470`). See [Run the hub](/hub/run/).

3. Link this machine.

   ```sh
   klark hub connect --url http://localhost:7470
   ```

   Open the link it prints, check the code, and press Approve. The link then runs in the background and this hub
   becomes your default. `klark hub stop` ends it; `klark hub ls` lists saved hubs. Your agents now show up in the hub.

</Steps>
