## The sidebar

- Only **agent panes** are listed. Plain shells and empty panes are hidden
  unless you tick **Show all panes** (remembered per browser).
- Agents are grouped by **project folder** (the pane's working directory name;
  hover for the full path). Groups collapse and stay collapsed.
- **Blocked agents first**, then the most recent activity.
- Each row: status dot, agent badge (Claude, Devin, Codex, other, shell), title,
  time since the last activity, and a one-line preview of the latest message.
- On desktop the sidebar collapses (the icon at the top). Up to 860 px wide it
  is a drawer. On a phone the list page *is* the sidebar.

## Search: ⌘K / Ctrl+K

Search matches every word you type (AND) against name, agent type, status,
folder, full path, session, machine and pane id.

It also searches the **text of every chat the hub holds in memory**. Hits show
under **Messages** with the match marked. Click one to open that chat scrolled
to the message.

## Where each URL goes

| URL | page |
|---|---|
| `/` | the agent list |
| `/m/{machine}/p/{pane}` | one agent's chat (`?view=terminal` for the terminal) |
| `/m/{machine}/f?pane=…&path=…` | the file viewer |
| `/go?machine=…&pane=…` | a share link from `klark expose url` |
| `/messages` | every agent message the hub routed; send as yourself |
| `/token` | a CLI token (JWT) for `klark msg` and scripts |
| `/account/password` | change your password |
| `/admin/users`, `/admin/directory`, `/admin/machines` | admin pages |

Back never leaves the app. The list keeps its search and scroll position, and
marks the chat you came from.
