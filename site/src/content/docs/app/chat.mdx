Opening a pane shows a **chat**, on every screen size. The live terminal opens
only from its toggle.

## What the chat gives you

- **Agent names in the list.** Each row in the sidebar shows the agent's name (what you gave it with
  `klark msg name`, else its title) with the agent kind and a preview of the latest message under it.
- **`/` autocomplete.** Type `/` in the composer and a popup lists the agent's slash commands.
  Claude Code and Devin get it with their full built-in command lists; Codex, agy (Antigravity), Gemini,
  OpenCode, Cursor, Copilot and Grok get lists too. Other agents and plain shells get no popup.
- **Slash-command answers in the chat.** `/context`, `/model`, `/status` and the like show what the
  agent printed, as a block in the chat, so you do not need the terminal.
- **File paths as links.** An absolute path in an answer opens a [preview](/app/files/). The hub asks the
  agent to name files by absolute path (the [agent note](/reference/hub-config/#the-agent-note)).
- **Phone view.** The same chat, one column, with a camera button for sending a photo to the agent.
- **[Themes](/app/tour/#themes).** Paper is the default.
- **Long chats stay fast.** Only the newest rows are drawn; **Show earlier** adds more.

- Your prompts and the agent's turns are separate blocks.
- Markdown renders properly: tables, lists, code blocks with a language label,
  a copy button and syntax highlighting.
- Tool calls and thinking fold into one-line rows, such as
  "Read 3 files · Ran 2 commands ✓". Click to open.
- A live line says working, idle or needs you.
- When the agent is **blocked** on a question, the question is shown with
  buttons for its numbered or yes/no options.

### Where the chat comes from

- **Claude Code** and **Devin**: their own structured logs (Claude's JSONL,
  Devin's SQLite), read by the machine.
- **Everyone else**: the pane's text, with the agent's screen chrome removed
  (borders, spinners, context meters, key hints, version banners) and split
  into turns. Boxed tables become real tables.

The hub polls a chat about once a second, only while someone has it open, and
shares one poll between all viewers of that pane. Only the newest 150 rows are
drawn; **Show earlier** adds more.

## Shells: command blocks

## File paths and the preview

When the agent writes an absolute path such as `/tmp/hubtest/claude-notes.txt`, the chat turns it into a
link. A click opens the file in the viewer, with line numbers, find, wrap, raw, copy and download.

## The composer

One box at the bottom: type, attach (**+**), send.

- **Enter** sends, **Shift+Enter** is a new line. **`/`** opens the command popup (arrow keys move, Tab or Enter pick, Esc closes).
- Typing never calls the server. Send delivers the text in one call.
- Read-only users (`Hub:Auth:ReadOnlyGroups`) see the chat but cannot type.

## The terminal toggle

The terminal icon in the top bar (or `?view=terminal` in the URL) opens the live
terminal.

- It is drawn at the **pane's real size**, scaled to fit the width, and
  scrolls sideways on narrow screens. TUIs render as they do on the machine.
- Esc and Ctrl-C work from the terminal tab.
- A viewer that falls more than ~2.5 s behind gets a fresh screen instead of a
  backlog.
- The terminal code (xterm) loads only the first time you open it.

## Images to the agent

On a pane, **paste, drop, pick (+) or photograph** an image (png, jpeg, gif,
webp, heic, avif; 20 MB at most). The machine downloads it to a private uploads
folder and the agent receives a prompt:

```text
[image from alice] <klark data dir>/uploads/<sha256>.png
```

The machine checks the SHA-256, stores the file with mode 0600, and sweeps
uploads after 24 hours.

You must be allowed to type in that pane. Uploads expire after 24 hours.
