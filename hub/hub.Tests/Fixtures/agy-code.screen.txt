> Write a short python function is_prime(n) with a docstring and one for loop, then one sentence.

    def is_prime(n: int) -> bool:
        """Return True if n is a prime number, else False."""
        if n < 2:
            return False
        for i in range(2, int(n**0.5) + 1):
            if n % i == 0:
                return False
        return True
  This function tests divisibility up to the square root of n to quickly determine if the number is prime.
